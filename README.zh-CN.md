# 高自由度载具（High Degree of Freedom Vehicles）

[English](README.md) · [繁體中文](README.zh-TW.md) · **简体中文**

Minecraft 1.21.1（NeoForge）的载具 Mod，用工程师的方式造车。每个零件都由你自己设计（发动机从缸体、曲轴到涡轮、喷嘴，
机翼、螺旋桨、旋翼、船身、车身、底盘、车轮与变速箱），在真正的机床工坊里做出来，再到组装室把载具组起来。
汽车、卡车、飞机、直升机和船；物理由 [AeroCore](https://github.com/fiseleo/aerocore) 计算。

> Beta（0.x）：版本之间会尽量让存盘继续能用，但格式仍可能变动。

## 功能

- **什么都能设计。** 每一种零件都有设计界面，即时检查、3D 预览与试算台：把发动机放上测功机、让机翼跑一遍极曲线、让车上测试场。
  活塞发动机（汽油与柴油、涡轮增压）、涡喷、涡扇、涡桨、涡轴、冲压、超燃、脉冲喷射、火箭、氢燃料。
- **自己做出来。** 新的矿物与冶炼、合金炉、铸造炉与锻压机、标准件、可以加长的多方块车床、铣床、刨床、镗床与钻床，
  九族机加工（磨床、齿轮、放电、激光、水刀、铆接……）、最多 12 轴的 CNC、焊接。每个零件都依自己的真实工序路线制作。
- **接上动力。** 踏板、蒸汽机、天轴、发电机、电线、电池，以及装在发动机台架上的你自己设计的发动机。
- **组起来。** 汽车厂、机库和造船厂：你自己盖的房间，在里面配置载具，由天车和焊工用你的零件造出来，再开出厂。
- **加油。** 油田、钻井架与抽油机、常压蒸馏塔与制程单元（FCC、重组、裂解、聚合）、加油机。
- **开出去。** 手动挡与自动挡变速箱、四驱、仪表、车灯；飞行操作、起落架、机场与有 ATC 的塔台；第五轮拖车。
- **改成你的。** 改装厂（造型、大小、空力套件、轮圈、调校、车灯）与可以贴自己图片的喷漆房。
- **保养与修理。** 零件会磨损，也会被撞坏、烧坏、泡水、生锈；修理厂与急修工具把它修好，超过 80 % 的换新零件。
- **载货。** 后备箱、货斗、货舱放的东西有重量；自己设计的车顶箱、货斗箱、集装箱；木箱、置物柜、零件架与装卸台。
- **听得到。** 所有声音都依运转中的发动机或机器即时合成。

## 怎么开始

新玩家会拿到《**载具工程手册**》：右键打开。它从第一块矿石一路教到第一台车、飞机和船，之后每个分支各一章。
进度界面有“高自由度载具”分页，跟着手册走；每个 hdfv 物品的说明都写着它的科技阶段与在哪里做。装了 JEI 的话，所有配方与机加工工序也都查得到。

## 多人与服务器

- 服务器设置（`serverconfig/hdfv-server.toml`）：一锭多少金属（10 公斤）、一个工作小时多久（1000 tick）；刀具磨耗与切屑回收；
  贴纸（上传、上限）；机场生成；新手教学的手册与欢迎消息。
- 贴纸是玩家上传的图片，服务器上所有人都看得到。管理员可以列出与删除：`/hdfv decal list|remove|purge`。
- 管理员：`/hdfv vehicle samples` 写出示例载具蓝图，给 AeroCore 的 `/aerocore vehicle spawn` 用。
- 客户端设置（Mod 清单 → 高自由度载具 → 设置）：开车、声音音量、航空单位。

## 从原代码建置

需要 JDK 21，以及放在旁边的 AeroCore 原代码：hdfv 用 AeroCore 的 Maven 文件夹建置（`../AeroCore/build/repo`；先在 AeroCore 运行 `publish`）。

```
./gradlew build                          # 遊戲 JAR 在 neoforge 的 build/libs
./gradlew :core:test                     # 單元測試（約 390 個）
./gradlew :neoforge:runGameTestServer    # GameTest（約 140 個）
```

Windows 上 `.\dev.ps1 build` 会自己找 JDK 21。开发用程序（GameTest、`/hdfv dev`、`/hdfvdev`、测试车）放在 `neoforge/src/dev`
与 core 的 test fixtures，不会发布；`verifyReleaseJar` 会检查 JAR。`tools/` 里是配方、资产与语言档的产生器（Python）
以及模型与贴图的 Blender 脚本。

## 已知限制

- 载具好不好全看设计：设计不好的车真的会慢，发动机选错真的会熄火。
- 物理都对照过公开数据，但仍是游戏用的物理（见 AeroCore 的文档）。
- 性能取决于同时运作的载具与机器数量；极高速的载具需要前方的世界已加载。
- 使用光影包（Iris）时零件改用原版着色；装了 Sound Physics Remastered 时，hdfv 自己的回响会关掉。
