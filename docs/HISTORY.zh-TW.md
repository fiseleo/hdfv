# High Degree of Freedom Vehicles（hdfv）

Minecraft Java 1.21.1／NeoForge 的載具 Mod，Mod ID `hdfv`。前置是同一個工作區的 [AeroCore](../AeroCore)（0.28 起）。

## 方向（使用者 2026-10-11 決定）

- 玩家自己設計零件，每個參數都能自由設定，形狀也是參數。引擎從缸體、汽缸蓋、曲軸、活塞、凸輪、進排氣，到壓縮機、渦輪、噴嘴逐項設定。
- 用自己做的零件組合出載具，陸、海、空都要。
- 合成是 CNC／機加工類：新增礦石與冶煉；機床先只花時間，之後加 Forge Energy 與發電機。
- 分工：「AeroCore 是計算 API」。零件本身（參數、檢查、藍圖 JSON、質量估計、執行時的控制規則）都在 hdfv；
  物理、性能計算、通用載具物理、同步與存檔在 AeroCore。
- 測試：設計畫面裡試算藍圖，測功機／推力台方塊測做出來的實物。設計畫面可由設計桌方塊或設計平板物品打開。

    階段由配方算出（資料包改了配方，提示跟著變）：
    - T0 工作台與爐：合金爐、鑄造爐、鍛壓機、組裝台、設計桌、踏板、碳鋼刀具；焦炭、坩堝鋼、灰鑄鐵、青銅。
    - T1 鑄鍛：鑄件、鍛件、軋製的鋼板與矽鋼片、銅線（A 級標準件）；第一批車床、鑽床、鉋床、蒸汽機、焊接台、複材爐、硫化機、變壓器、電弧爐、電解槽。
    - T2 機加工與電：車削軸、導螺桿、螺栓組、鋼管、刨削導軌、閥體、搪孔汽缸、電路板（B 級）；銑床、搪床、發電機、電動機、泵、煉油與石化設備、空氣分離機；
      鋁、鎂、鉻、鈦、合金鋼、不鏽鋼、超合金。
    - T3 精加工：切削齒輪、滾動軸承、磨削導軌、主軸（C 級）；磨床、齒輪機與 0.17 的九族、伺服馬達、數控驅動座、鑽井架、抽油機、塔台雷達。
    - T4～T5 數控：滾珠螺桿、CNC 加工中心；線性滑軌與精密主軸（D 級）之後才有電加工、切割台與 CNC 的刀塔、副主軸、送料機。
  - **標準件**（新的設計分類「標準件」，26 種，固定設計）：在設計畫面選種類、存進空白藍圖，放上機器照常加工，最後一步做完就是一個標準件物品。
    A 級在鑄造爐與鍛壓機做（床身鑄件 40 kg、機架鑄件、汽缸鑄件、鑄齒輪、皮帶輪、青銅軸套、鍛造軸、鍛造曲柄、鋼板、矽鋼片、銅線），
    B 級要車床、鑽床、鉋床，C 級要銑床、磨床、齒輪機，D 級要 CNC、精磨與電加工。
  - **組裝台組機器**：組裝台的圖紙格空著時，放進標準件就照「組裝」配方組（要人在旁邊、花工時：300 秒＋每件 60 秒＋每 kg 3 秒）；
    符合好幾個配方時先組用料最多的，畫面上的按鈕可以換。放了圖紙時照舊組零件。電動機、變壓器、控制板、伺服馬達、泵、液壓缸、齒輪組、
    熱交換器是中間件，也在組裝台組。機器、頭、驅動、動力、石油設備與塔台電子都在組裝台；成員、建材、燈、電線、管線仍用工作台。
  - **統一的遊戲尺度**：約真實質量的十分之一，每類一個範圍（機器 40～300 kg 的金屬、成員每格 5～80 kg、頭與附件 10～120 kg、建材 0.3～25 kg、
    燈與電線 0.1～6 kg），產生器與測試都檢查。
  - **冶金**（兩台新的電力機器，單一方塊，吃電，用電量由 AeroCore 0.40 的冶金計算算出）：
    - **電弧爐**（100 kW）：鋼（每 kg 約 0.4 kWh）、合金鋼、不鏽鋼、閥鋼、因科鎳、CMSX-4、鈦合金重熔（要氬氣瓶）、75 % 矽鐵、高碳鉻鐵、
      鈦渣（鈦鐵礦＋焦炭，副產鐵粒）、Kroll 法海綿鈦（鈦渣＋鎂＋焦炭＋氬，副產氯化鎂）、瀝青碳纖維。
    - **電解槽**（60 kW）：鋁（氧化鋁＋碳陽極，每 kg 約 13 kWh）、鎂（氯化鎂，Kroll 的鎂回收）、過氯酸銨（火藥＋紅石）。
    - **合金爐**（照舊燒燃料）：焦炭與煤焦油、坩堝鋼、灰鑄鐵、球墨鑄鐵、青銅、鋁合金與鎂合金的熔配、複材料件、重熔；
      新增鋁土礦煅燒成氧化鋁、鉻鐵礦焙燒成氧化鉻、菱鎂礦煅燒成氧化鎂、碳陽極、Pidgeon 法鎂（氧化鎂＋矽鐵）、鋁熱法鉻（氧化鉻＋鋁，副產氧化鋁）。
      漏斗與管線可以接：上方進料、側面進燃料、下方出料。焦炭可以當燃料（合金爐、鑄造爐、蒸汽機）。
    - 拿掉的舊路線：合金爐的鋁、鉻、鎂、鈦、碳纖維、過氯酸銨，以及合金鋼、不鏽鋼、閥鋼、因科鎳、CMSX-4、鈦的料件。
  - **化學品、燃料與推進劑**：煤焦油路線保留但比石化貴（環氧 3:1、合成橡膠 3 煤焦油＋火藥出 2）；製程單元的重組反應器也能用 LPG 與水做甲醇；
    聚丙烯可以代替橡膠做電線絕緣、做蓄電池外殼。推進劑質量守恆（每個藥柱 1 kg）：KNSB 2 火藥＋1 糖出 3；APCP 14 過氯酸銨＋3 鋁料塊＋3 橡膠料塊出 20。
  - **機加工**：
    - 切屑回收：切削與磨削去除的金屬有 80 % 以料塊回到輸出（伺服器設定 `chipRecovery`）；複材與橡膠不回收。
    - 碳鋼刀具組（工作台：兩個鋼料塊＋煤）：速度約高速鋼的四成、壽命短、可重磨，T1 的機床不用等鉻就能切削。
    - 修正：機器只在成品與料頭都放得下時才開工（以前只剩一格空位時會弄丟其中一個）。
  - **相容**：配方材料改吃 `c:` 標籤（其他 Mod 的鐵錠、銅錠、玻璃、染料…都能用）；加 `c:ingots/aluminum`（美式拼法）、`c:coal_coke`、`c:plates/steel`、
    `c:wires/copper`、`c:raw_materials/garnet` 與流體標籤（`c:diesel`、`c:crude_oil`…，管線與加油機也認其他 Mod 的這些流體）；
    其他 Mod 的鋼錠、青銅錠在工作台換成 hdfv 的料件。裝了 Create 時多出：粉碎礦石、把鋼料壓成鋼板、加熱攪拌青銅（沒裝就不載入）。
  - **既有世界**：已放的機器、多方塊與工廠照常運作；已有的設計與做到一半的工件，工序與工件都不變；合金爐裡的東西不會消失；沒有物品被移除。
  - **已知限制**：潤滑油與燃料油還沒有配方用途；Create 只有配方相容，沒有動力互通；標準件不能改參數。

## 建置

hdfv 從 `../AeroCore/build/repo` 取用 AeroCore（版本見 `gradle.properties` 的 `aerocore_version`）。
AeroCore 有改動時，先在 AeroCore 執行：

```powershell
.\dev.ps1 build publish
```

再在這裡執行：

```powershell
.\dev.ps1 build
.\dev.ps1 :neoforge:runGameTestServer
.\dev.ps1 :neoforge:runClient
```

遊戲資料在 `%USERPROFILE%\.mcmod\runs\hdfv`（每台電腦各一份，不放在網路資料夾）。
